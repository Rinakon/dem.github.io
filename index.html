📁 Файл 2: doctor_primary_index.drawio

Запрос: "Показать все данные по сущности ВРАЧ"

Тип индекса: Кластеризованный B+Tree по первичному ключу

[ ROOT: ID_Врача Range ] │ ├─► [100-150] ──► [Leaf:101] ──► {Иванов И.И., Хирург, 10лет, LIC-001} │ [Leaf:102] ──► {Петрова А.С., Ортодонт, 5лет, LIC-002} │ └─► [151-200] ──► [Leaf:151] ──► {Сидоров П.П., Терапевт, 15лет, LIC-003} [Leaf:152] ──► {Козлова Е.В., Гигиенист, 3лет, LIC-004} 🔍 Поиск по ID_Врача = 101: 1. Root → диапазон [100-150] 2. Переход к листу [Leaf:101] 3. Возврат ПОЛНОЙ записи врача (все 5 атрибутов)

Ключ индекса

ID_Врача (INTEGER, UNIQUE, NOT NULL)

Структура

B+Tree, высота ~log₂(N), листовые узлы содержат полные данные

Сложность

Поиск: O(log N), Вставка: O(log N)

🚀 Как выложить 7 файлов на сайт

  1. Создай репозиторий на GitHub:
    • Зайди на github.com
    • Нажми "New repository" → название: dental-db-model
    • Выбери Public → Create
  2. Скачай/создай 7 файлов:
    • Нажми кнопки "Скачать .drawio" выше для каждого файла
    • Или скопируй XML-код через "Копировать XML"
    • Сохраните как: hierarchy_model.drawio, doctor_primary_index.drawio, и т.д.
  3. Загрузи файлы:
    • В репозитории: Add file → Upload files
    • Перетащи все 7 файлов → Commit changes
  4. Включи GitHub Pages:
    • Settings → Pages → Branch: main → Save
    • Через 1-2 минуты появится ссылка:
      https://твое-имя.github.io/dental-db-model/
  5. Отправь ссылку преподавателю! 🎉
