СУЩНОСТЬ: Операция
ВТОРИЧНЫЕ ИНДЕКСЫ:

1. По Дате (Date/Datetime) -> B-Tree. Критично для расписания. Позволяет быстро искать операции за период.
2. По Стоимости (Decimal) -> B-Tree. Для поиска "дорогих" или "дешевых" операций.
3. По Названию (Text) -> Hash или B-Tree. Для быстрого поиска типа "Удаление зуба".
